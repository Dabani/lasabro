# Security policy

**Do not open a public issue for a vulnerability.** Write to **dabani.rm@gmail.com** (subject "LASABRO security") with what you
found, how to reproduce it, and the version or commit. You will get an acknowledgement within 5 working days and, once the issue is fixed,
credit in the release notes if you wish.

Supported versions: the latest release of each plugin and of the kit. Never commit database dumps, `.env` files, keys or real
personal data; if you find any in the repository, report it the same way.
