# LASABRO brand kit

Source: `logo-horizontal-light.svg` (supplied). Everything else is derived from its vector paths, nothing is redrawn.

| File | Use |
|---|---|
| `logo-horizontal-light.svg` | Full logo "LASABRO Enterprise" on white / light surfaces |
| `logo-horizontal-dark.svg` | Same logo in white, for dark themes and coloured backgrounds |
| `icon.svg` | The mark alone (colour): app icon, avatar, loading screen |
| `icon-white.svg` | The mark in white (accent at 62 % opacity keeps the two-tone shape) |
| `icon-mono.svg` | One-colour mark using `currentColor`: inherits the text colour of its container |
| `wordmark.svg`, `wordmark-white.svg` | "LASABRO" without the edition line. Future editions (Sports, Medical...) combine it with their own edition text |
| `favicon.svg` | Mark on a white rounded square so it stays legible at 16 px |
| `png/` | `icon-192`, `icon-512`, `icon-maskable-512` (white mark on green, inside the safe zone), `apple-touch-icon` (180), `favicon-32`, `logo-horizontal-light` (1200 px) |

## Colours
| Token | Hex | Role |
|---|---|---|
| `brand.green` | `#177306` | Primary: mark, wordmark, primary buttons and links |
| `brand.red` | `#731706` | Accent: the small slab in the mark, destructive emphasis, highlights |
| white | `#FFFFFF` | Logo on dark / green backgrounds |

Dark surfaces: use the `*-white` / `logo-horizontal-dark` files, never the green logo (contrast too low).

## Rules
Clear space around the logo: at least the height of the "L". Minimum size: mark 16 px, horizontal logo 120 px wide.
Do not recolour, rotate, stretch, outline or add effects. Edition names (Enterprise, Sports...) are the second line of the
horizontal logo; keep the same letter-spacing when you create another edition.
